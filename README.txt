LAMU AI GitHub Pages

This ZIP contains a ready-to-publish static browser demo.
Extract it and upload index.html to the root of your GitHub repository.
Then open repository Settings > Pages, choose Deploy from a branch, select main and /(root), and Save.
Once GitHub finishes, it will show your Pages website URL.

Note: This is a browser demo. Full AI requires a separately hosted backend. Browser wake-word listening in background is not supported reliably.
